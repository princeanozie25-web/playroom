## Anti-patterns verdict

**Does it look AI-generated? No — from a screenshot of the transcript, nobody would say so.** The
strangeness is purposeful (mandate surface, sentence-form decision card), density gradient is real,
and the mechanical tells that betray generated UI (gradient text, glassmorphism, hero metrics, card
grids, decorative motion, modal reflex) are all absent. A design-literate eye would say "Tailwind
defaults" — the palette, not the structure, is where the training-data reflex shows.

**Deterministic CLI scan** (`npx impeccable@3.5.0 detect --json apps/web/app`, exit 2):
**4 findings / 1 distinct rule / 21 scannable source files (20 tsx + globals.css via layout import)
/ 58 rules in the registry (release notes: 29 deterministic static).** All four are `side-tab`
(side-stripe accent border), globals.css lines 639 (`.decision`, indigo), 915 (`.interrupt-chip`),
1075 (`.join-error`), 1319 (`.loop-row`). Impeccable's absolute-ban list calls this "never
intentional"; here every one is documented intent — `design-ruled:` design.md "The three cards"
itself specifies "Left border 3px amber" for the DECISION card, and globals.css carries reasoned
comments at each site. Detector-vs-contract collision resolved in design.md's favour; recorded in
`ignore.md` so future runs do not re-raise what an owner ruling settles.

**Browser-injected detector** (rendered room, real roster): **6 findings / 5 elements / 3 distinct
rules.** 4× thin-border-wide-shadow on `.mandate-detail` (1px border + 24px shadow blur — the
popover); body-level: "Primary font: roboto (100% of text)" (the system stack resolving generically
in Chromium/Windows; Inter/serif signature is OPEN-2, unadopted) and "Sizes: 11px, 13px, 15px, 19px
(ratio 1.7:1)" (compressed overall range; product register tolerates tight scales, noted not
actioned).

**Where A and B agree:** the left-rule family (A found five including `.promotion-body` 2px; the

## Priority issues (combined)

1. **[P1] The ambient text tier fails the contract's own contrast floor.** `--ink-3 #94a3b8` on
   white ≈ 2.6:1 against DESIGN.md's promised 4.5:1 — and it is the text ink for the room meter,
   spend footers, kickers, decision hash, order meta, interrupt budget, and the 10px full hash.
   Fix: darken the muted ink for text use (≥4.5:1), keep the pale value for borders/markers only.
2. **[P1] Three promised a11y mechanisms are unimplemented.** No `:focus-visible` ring on any
   button/summary/link; no `prefers-reduced-motion` anywhere (two animations run regardless); no
   `aria-live` on the streaming transcript. All three are explicit design.md "Tokens"/A11y
   commitments. Fix: global focus ring; reduced-motion kill block (lands with SHELL-B2's motion,
   where its mechanism test lives); `aria-live="polite"` on the transcript.
3. **[P1] The primary action is recall-only and fails silent.** Placeholder says "message"; the
   @-convention lives only in the dismissable Welcome; an untagged/mistyped tag produces nothing.
   Static half (placeholder copy per design.md "The composer") is craft; the affordance/system-line
   half is product behaviour — logged, not fixed in this slice (standing rule).
4. **[P1] Live events yank a reading user to the tail.** `scrollIntoView` on every items change
   except prepends. Behaviour — logged for a successor slice, not fixed in a craft pass.
5. **[P2] Undeclared tokens carry state meaning** (`--amber`, `--rose`, `--mono` exist only as
   `var()` fallbacks; = SHA-A-F2 + `--mono`). The shipped second amber `#d97706` ≠ contract amber
   `--warn #b45309`; rose `#e11d48` (hue ~347) sits beside principal accent `--p3 #be185d` (336) —
   the adjacency the palette was engineered to avoid. Fix in this slice: bind amber uses to
   `--warn`; declare `--rose` and `--mono` in `:root`; record the BLOCKER-hue-vs-`--p3` question for
   the owner.

## The register tests

**Register: product** (identified from the surface: authenticated app UI, user in a task; design
serves). **Product slop test:** "would a user fluent in Linear/Figma/Notion/Stripe sit down and
trust this, or pause at every subtly-off component?" — verdict: trust, with pauses at exactly the
seams named above (dead controls indistinguishable by cause; three capitalization voices).
**Inverse test (brand.md, run against this product surface):** "describe the page the way a
competitor would describe theirs" → *"a clean chat room where you can @-mention AI assistants and
see what they're allowed to do"* — the first clause fits any generic AI-chat landing page; **the
second clause does not exist anywhere else**, and it is carried by the roster's mandate summaries,
the mandate surface, and the decision card. The page does NOT read as generic — but only when a
mandate-bearing chip or a decision card is in frame; a screenshot of bare messages reads as a stock
chat surface. The signature elements are the differentiation; the craft pass must not quiet them.
