03 — The rules

Quiet, deliberate, enforced.

R·01 Nothing renders that the log didn't produce. Every chip, card, and status points to a real event — or it is visibly disabled with an honest label. There is no third state. This page plays by the same rule: every surface on it is one the contract specifies, in a state the fabric could produce — nothing invented.
R·02 Protected actions stop for a signature. Agents hold the pace; a person holds the pen. The co-sign approves that exact action — not a vibe, not a session, not a blanket yes.
R·03 Watching is free. Acting is scoped. Reads stream live and cost nothing to trust. Writes carry a mandate — and a member with no mandate shows no mandate, never an implied "unrestricted."
